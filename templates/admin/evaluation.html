Problem Formulation: Supervised Regression Task

Supervised Regression

House price prediction is fundamentally a continuous numerical regression problem, not a discrete classification problem. The objective is to estimate the expected market value in Indian Rupees (Market_Price_INR) as a continuous function of 18 property attributes. Evaluating continuous home prices using classification metrics directly is mathematically invalid; regression error metrics (MAE, RMSE, and R²) provide the genuine measure of dollar accuracy.
